Address Book Application Documentation

Objective:
To develop a command-line address book application in C that provides efficient contact management with data persistence, input validation, and user-friendly interface.

System Requirements:
- C compiler (GCC recommended)
- Standard C libraries
- Text editor for viewing contacts.txt

Features:
- Create new contacts with validation
- Search contacts by name, phone, or email
- Edit existing contact information
- Delete contacts from address book
- List all contacts with sorting options
- Automatic data persistence to file
- Input validation with error handling
- Duplicate contact prevention

Data Structures:
Contact Structure:
- char name[50] - Contact name
- char phone[20] - Phone number
- char email[50] - Email address

AddressBook Structure:
- Contact contacts[MAX_CONTACTS] - Array of contacts
- int contactCount - Current number of contacts
- MAX_CONTACTS = 100 - Maximum capacity

File Handling:
File Operations:
- saveContactsToFile() - Write contacts to CSV file
- loadContactsFromFile() - Read contacts from CSV file
- File format: contacts.txt (CSV format)
- Auto-save on program exit
- Auto-load on program startup

File Format:
- Each line: name,phone,email
- Example: John Doe,9876543210,john.doe@example.com
- Location: Same directory as executable

Algorithms:
Search Algorithm:
- Linear search through contact array
- O(n) time complexity
- Case-sensitive string comparison

Sorting Algorithm:
- Bubble sort implementation
- O(n^2) time complexity
- Sort by name, phone, or email
- In-place sorting with temporary variable

Validation Algorithm:
- Name: Alphabetic characters and spaces only
- Phone: 10 digits starting with 6-9
- Email: Contains '@', ends with '.com'
- Three attempt limit per input

Menu System Algorithm:
- Do-while loop for continuous operation
- Switch-case for menu selection
- Exit condition on option 6

Advantages:
    Simple and efficient contact management
    No external database required
    Fast operation for small datasets
    Portable across different systems
    Low memory footprint
    Easy to maintain and modify
    Secure input validation
    Data persistence ensures no data loss

Limitations:
    Maximum 100 contacts limit
    No backup/restore functionality
    No import/export capabilities
    No partial search support
    No contact categorization
    Case-sensitive search operations
    Plain text storage (no encryption)
    Single user support only

Error Handling:
    Input validation with retry mechanism
    File operation error checking
    Buffer overflow protection
    Duplicate detection
    Graceful failure recovery
    User-friendly error messages

Compilation and Execution:
    Compile: gcc main.c contact.c file.c validation.c -o addressbook
    Run: ./addressbook

Function Prototypes:
    main() - Program entry point and menu system
    initialize() - Initialize address book
    createContact() - Add new contact with validation
    searchContact() - Find contacts by criteria
    editContact() - Modify existing contact
    deleteContact() - Remove contact from list
    listContacts() - Display sorted contacts
    validate_name() - Validate name format
    validate_phone() - Validate phone format
    validate_email() - Validate email format

Conclusion:
The Address Book Application successfully provides a complete contact management solution with essential CRUD operations, data persistence, and input validation. While it has limitations in terms of scalability and features, it serves as an excellent foundation for understanding file-based data management, input validation, and menu-driven programming in C. The application demonstrates key programming concepts including data structures, file I/O, algorithms, and error handling in a practical, real-world context.
